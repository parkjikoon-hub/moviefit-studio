# memory/ — 개발 교훈 저장소 규칙

이 폴더는 개발 에이전트(Claude Code)가 세션을 넘어 교훈을 유지하기 위한 공간이다.
**새 세션을 시작할 때 반드시 이 폴더의 파일들을 먼저 읽는다.**

## 규칙

1. **파일 하나에 교훈 하나.** 파일명은 내용을 짐작할 수 있게: `edge-tts-rate-format.md`, `ffmpeg-korean-path.md`
2. **맨 위 첫 줄은 한 줄 요약.** 그 아래에 상세: 무슨 일이 있었고, 무엇이 통했고, **왜 중요한지**.
3. 수정된 실수와 확인된 접근법을 **모두** 기록한다. 성공 경험도 자산이다.
4. 저장소 코드나 docs/ 문서가 이미 담고 있는 내용은 저장하지 않는다.
5. 같은 주제의 새 교훈은 새 파일 대신 **기존 파일을 갱신**한다.
6. 틀린 것으로 판명된 노트는 **삭제**한다.

## 예시 형식

```
FFmpeg 자막 필터에 Windows 경로를 넣을 때는 콜론과 역슬래시를 이스케이프해야 한다.

상황: ass=C:\projects\... 형태로 전달하자 필터 파싱 오류 발생.
해결: 경로를 ass='C\:/projects/...' 형태로 변환하는 함수를 app/core/ffmpeg.py에 두고
모든 필터 경로가 이 함수를 거치게 함.
중요한 이유: 이 오류는 메시지가 모호해서 매번 30분씩 잃게 만든다.
```

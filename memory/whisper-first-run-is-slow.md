음성인식 첫 실행은 모델을 내려받느라 6분쯤 걸린다. 이걸 사용자에게 미리 알리지 않으면 "멈췄다"고 생각하고 창을 닫는다.

측정값 (2026-08-12, CPU 전용 노트북):
- `small` 모델 = **486.2 MB**, 첫 실행 총 **349.9초** (거의 전부 내려받는 시간)
- 두 번째 실행부터는 **0.0초** 만에 모델이 뜬다 (캐시)
- 저장 위치: `C:\Users\<사용자>\.cache\huggingface\hub`
- 장치 선택 결과: `cpu / int8` (이 PC에 CUDA 장치 0개)
- `medium` 모델은 약 1.5GB로 추정되며 아직 실측하지 않았다

그래서 반드시 지킬 것:
1. 모델을 불러오기 **전에** "처음 한 번은 500MB쯤 내려받습니다. 몇 분 걸릴 수 있습니다"를
   진행률 메시지로 먼저 띄운다. 내려받는 동안은 진행률이 올라가지 않으므로 문구가 유일한 단서다.
2. `medium`(정확) 선택지 옆에 "처음 한 번 1.5GB를 더 받습니다"를 적는다.

함께 확인된 것:
- `vad_filter=True`를 켜면 무음 구간에서 없는 말을 지어내는 현상(hallucination)이 줄고,
  소리가 없는 파일은 아예 0초 만에 끝난다. onnxruntime이 함께 깔려 있어야 동작한다.
- 사용자 사전(F-12)이 실제로 값을 한다: whisper가 "무비피"로 잘못 들은 것을
  `무비피 → 무비핏` 규칙이 고쳐 주었다. 고유명사가 있는 영상이면 사전을 먼저 채우게 안내하는 편이 좋다.

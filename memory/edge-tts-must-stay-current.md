edge-tts(무료 나레이션 음성 부품)는 **마이크로소프트가 접속 규칙을 바꾸면 옛 판이 403 으로 통째로 막힌다.** 배포한 지 몇 달 지나면 나레이션이 조용히 죽어 있을 수 있다. 오류 이름은 `WSServerHandshakeError` 이고, 화면에는 "인터넷 연결을 확인하세요"로 나온다.

무슨 일이 있었나 (2026-11-04):
타임라인 작업 뒤 전체 점검을 돌렸더니 나레이션을 만드는 점검 넷(phase2·ducking·phase4·voice_language)이
같은 오류로 실패했다. 인터넷은 멀쩡했다. 직접 불러 보니:

    7.2.8 (설치된 것, v0.6.0 설치 파일에도 이 판)  → 403 Invalid response status
    7.3.1 (그때 최신, 임시 폴더에 따로 받아 시험)  → 성공

즉 **v0.6.0 을 받은 모든 사람이 그 시점부터 나레이션을 못 만든다.** 이 프로그램의 핵심 기능이다.

고친 것: `requirements.txt` 를 `edge-tts>=7.3.1` 로 올리고 개발 환경을 7.3.1 로 올렸다.
설치본은 **새 설치 파일을 만들어 배포해야** 고쳐진다. 설치본에는 pip 이 없다 ([[installed-app-needs-restart]]).

다음에 할 일:
- 배포 전 체크리스트에 "`python -m pip index versions edge-tts` 로 최신 판 확인"을 넣는다
- 진단할 때는 개발 환경을 건드리지 말고 `pip install --no-deps --target <임시폴더> edge-tts==<새판>` 으로 따로 받아 시험한다
- "인터넷 연결을 확인하세요"라는 안내는 403 일 때 틀린 말이다. 사용자는 인터넷이 멀쩡한데도 계속 다시 누른다 ([[tts-voice-must-match-text-language]] 와 같은 종류)

중요한 이유: CLAUDE.md 가 TTS 어댑터를 따로 두라고 한 바로 그 위험이 실제로 일어났다. 이번에는 판만 올리면 됐지만, 다음에는 edge-tts 자체가 막힐 수도 있다.

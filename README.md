# SubCap Studio 개발 키트 — 사용 안내

> **자막·나레이션 특화 프로그램 (CapCut의 자막/나레이션 기능을 능가하는 나만의 도구)**
> 이 폴더 전체를 개발 프로젝트 폴더에 복사한 뒤, Antigravity IDE의 Claude Code에게 개발을 맡기기 위한 키트입니다.

---

## 1. 이 키트에 들어있는 것

| 파일 | 역할 | 누가 읽는가 |
|---|---|---|
| `README.md` | 지금 보고 계신 사용 안내 | 교수님 |
| `CLAUDE.md` | 개발 에이전트(Claude Code)의 행동 규칙 — 자동으로 읽힘 | Claude Code |
| `PROMPTS.md` | 복사해서 붙여넣는 프롬프트 모음 (킥오프 + 단계별 + 검증) | 교수님 → Claude Code |

## 2. 시작 전 준비물

1. **Antigravity IDE + Claude Code** 가 설치되어 있어야 합니다.
2. **Python 3.11 이상** — 없어도 됩니다. Phase 0에서 Claude Code가 설치를 안내합니다.
3. **FFmpeg** — 역시 없어도 됩니다. Phase 0에서 Claude Code가 설치를 안내합니다.
4. 인터넷 연결 — 최초 1회 음성인식 모델 다운로드와 나레이션(TTS) 생성에 필요합니다.

## 3. 사용 순서 (5단계)

1. **폴더 복사** — 이 키트 폴더의 내용 전부를 새 프로젝트 폴더(예: `C:\projects\subcap-studio\`)에 넣습니다.
2. **Antigravity에서 그 폴더를 엽니다.**
3. **Claude Code를 실행합니다.**
   - Claude Code는 `CLAUDE.md`를 자동으로 읽습니다.
   - 만약 Antigravity의 자체 에이전트(Gemini 등)를 쓰신다면 `CLAUDE.md`를 복사해서 `AGENTS.md`라는 이름으로 하나 더 만들어 두세요. (내용 동일, 이름만 다름)
4. **`PROMPTS.md`를 열고 "프롬프트 0 — 킥오프"를 통째로 복사해 붙여넣습니다.**
5. 이후에는 단계가 끝날 때마다:
   - "검증 프롬프트"를 붙여넣어 스스로 검사하게 하고,
   - 통과하면 다음 단계 프롬프트를 붙여넣습니다.

## 4. 진행 중 꼭 기억하실 것

- **한 번에 한 단계씩.** 단계를 건너뛰자고 하면 거절하셔도 됩니다. ROADMAP의 수용 기준이 전부 통과된 뒤 다음 단계로 가는 것이 안전합니다.
- Claude Code가 "이제 ~를 하겠습니다"라고 말만 하고 멈추면, **"계속"** 또는 **"끝까지 진행해"** 한 마디면 충분합니다.
- 오류가 나면 오류 메시지를 그대로 복사해서 `PROMPTS.md`의 "오류 해결 프롬프트" 틀에 넣어 붙여넣으세요.
- 대화가 길어져 새 세션으로 옮길 때는 "인수인계 프롬프트"(PROMPTS.md 맨 아래)를 사용하세요. `memory/` 폴더 덕분에 교훈이 유지됩니다.

## 5. 완성되면 어떻게 실행하나

Phase 1이 끝나면 프로젝트 폴더에 `run.bat`이 생깁니다. **더블클릭하면 브라우저가 열리며 프로그램이 실행됩니다.** 설치형 프로그램이 아니라 "내 컴퓨터 안에서만 도는 웹앱" 방식이라, 비개발자 입장에서 설치·배포 문제가 가장 적은 구조입니다.

## 6. 알아두실 한계 (정직한 고지)

- **나레이션 음성은 Microsoft Edge의 무료 신경망 음성(edge-tts)을 사용합니다.** 품질이 매우 좋고 무료지만 비공식 경로라 언젠가 막힐 수 있습니다. 그래서 TECH_SPEC에 교체 가능한 구조(어댑터 방식)로 설계해 두었고, 막히면 다른 TTS로 갈아끼우기만 하면 됩니다.
- **음성인식(자막 생성)은 로컬 Whisper를 사용합니다.** 무료·개인정보 안전이 장점이나, CPU만 있는 PC에서는 CapCut 클라우드보다 처리 시간이 더 걸릴 수 있습니다(10분 영상 기준 수 분). 정확도는 모델 크기 선택과 "사용자 사전" 기능으로 보완합니다.
- **CapCut 프로젝트 파일(.draft)은 열 수 없습니다.** CapCut의 저장 형식은 비공개라서, 이 프로그램은 일반 영상 파일(mp4 등)을 직접 다룹니다.
- CapCut의 **기능**을 참고해 만드는 것은 문제가 없으나, CapCut의 **아이콘·로고·화면 디자인 자산을 그대로 베끼는 것은 금지**로 설계에 명시했습니다.

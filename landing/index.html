MovieFit Studio

영상에서 자막을 자동으로 뽑고, 대본에서 나레이션과 자막을 한 번에 만드는 무료 윈도우용 도구.

내려받아 실행하면 브라우저에 작업 화면이 열립니다. 파이썬이나 FFmpeg를 따로 설치할 필요가 없습니다. 회원가입도, 결제도, 워터마크도 없습니다.

왜 만들었나

자막과 나레이션, 이 두 가지만 제대로 하는 도구

영상 편집기는 기능이 많은 대신, 자막을 고치고 나레이션을 붙이는 일상적인 작업이 오히려 번거롭습니다. MovieFit Studio는 영상 편집기가 아닙니다. 자막과 나레이션 두 가지 작업만 남기고 나머지를 모두 걷어낸 전용 도구입니다.

  • 1

    자막을 문서처럼 편집

    타임라인에서 클립을 하나씩 클릭하는 대신, 전체 자막을 한 화면 목록으로 봅니다. 글자를 바로 고치고, 찾기·바꾸기로 잘못 인식된 단어를 한 번에 정리하고, 시작·끝 시간은 ±0.1초 버튼으로 정확히 맞춥니다.

  • 2

    나레이션과 자막이 자동으로 맞춰짐

    대본을 붙여넣으면 문장마다 나레이션 음성을 만들고, 그 음성의 실제 길이를 재서 자막 시간을 계산합니다. 소리와 자막이 어긋날 일이 구조적으로 없습니다. 손으로 싱크를 맞추지 않아도 됩니다.

  • 3

    내 컴퓨터에서만 처리

    음성 인식은 컴퓨터 안에서 도는 Whisper 모델이 담당합니다. 영상과 오디오 파일은 어디로도 올라가지 않습니다. 업로드를 기다릴 필요도, 남의 서버에 내 영상을 맡길 일도 없습니다.

기능

무엇을 할 수 있나

아래 항목은 실제로 동작하며 자동 점검을 통과한 것들입니다. 아직 만들지 않은 것은 계획으로 따로 표시했습니다.

영상 → 자막 동작

  • 영상(mp4·mov·mkv·webm)과 오디오(mp3·wav·m4a) 불러오기
  • 컴퓨터 안에서 도는 Whisper로 자동 음성 인식 (한국어·영어·자동 감지)
  • 정확도 선택: 빠름 / 정확 — 예상 소요 시간 안내와 진행률 표시
  • 문장 부호와 글자 수 기준으로 자막을 알맞게 끊어 줌
  • 작업 내용 자동 저장 — 프로그램을 껐다 켜도 그대로 남습니다

자막 편집기 동작

  • 목록에서 글자를 바로 고치는 인라인 편집
  • 자막 추가·삭제·합치기, 커서 위치에서 나누기
  • 시작·끝 시간 ±0.1초 버튼과 직접 입력
  • 아래쪽 타임라인에서 막대를 끌어 시간 조절, 소리 파형 표시
  • 읽기 속도가 너무 빠른 자막을 색으로 경고, [자막 검사]로 문제 일괄 점검
  • 찾기·바꾸기, 되돌리기/다시하기, 전체 시간 밀기
  • 사용자 사전 — 자주 틀리는 고유명사 자동 교정
  • 말이 끊기는 곳을 찾아 자동으로 나누기, 스페이스바로 타이밍 찍기

AI 나레이션 (TTS) 동작

  • 대본 붙여넣기 → 문장별로 나누어 음성 생성
  • 마이크로소프트 Edge 신경망 음성 — 한국어로 쓸 수 있는 목소리 14종, 무료
  • 목소리 미리듣기, 속도·높낮이·크기 조절, 문장 사이 간격 설정
  • 자막 시간 자동 계산 — 각 문장 음성의 실제 길이 기준
  • 한 문장만 고쳐서 그 문장만 다시 생성 (이후 시간 자동 재계산)
  • 문장마다 다른 목소리·속도·쉼 지정
  • 만든 자막을 나레이션용 대본으로 바로 전환
  • 계획 내 목소리를 등록해 그 목소리로 나레이션

내보내기 동작

  • SRT·VTT 자막 파일 — 유튜브·프리미어 등에서 그대로 사용
  • SRT·VTT 파일 가져오기
  • 자막을 영상에 새겨 넣은 mp4 (한글 폰트 함께 제공)
  • 10초 미리보기 — 전체를 만들기 전에 자막 모양 확인
  • 나레이션 오디오 단독 저장 (mp3 / wav)
  • 영상에 나레이션 입히기 — 원본 소리 볼륨 0~100% 조절, 자동 덕킹
  • 진행률 표시와 완료 후 저장 폴더 열기

자막 스타일 동작

  • 프리셋 5종: 기본 / 예능 / 뉴스 하단바 / 미니멀 / 강조
  • 글꼴·크기·자간·줄간격·색·외곽선·그림자·반투명 배경 박스
  • 자막을 마우스로 끌어 원하는 자리에 배치 — 영상에 새길 때도 같은 자리
  • 세로 영상(쇼츠·릴스)용 한 번에 맞추기, 가려지는 영역 안내선
  • 바꾸는 즉시 미리보기에 반영, 내 프리셋으로 저장

화면 효과 동작

  • 16가지 효과를 원하는 구간에만 — 타임라인에 막대를 놓고 끌어서 옮깁니다
  • 비·눈·물방울 맺힘·비눗방울·작은 폭죽·줌 강조
  • 부분 흐림(얼굴 가리기)·주변 어둡게·가장자리 어둡게·네모 테두리
  • 따뜻하게·차갑게·선명하게·빈티지·흑백·밝기/대비/채도
  • 세기 3단계와 진하기 20~200%, 자리·크기·속도까지 조절

만들지 않는 것

  • 컷 편집·장면 전환·스티커 등 일반 영상 편집 기능
  • 클라우드 협업, 계정 시스템, 모바일 앱
  • 다른 편집 프로그램의 프로젝트 파일 호환

기능을 줄이는 것이 이 프로젝트의 설계 의도입니다. 자막과 나레이션 작업이 두 번의 클릭 안에 끝나도록 화면을 평평하게 유지합니다.

현재 상태 (2026년 8월 15일): 자막 생성·편집, 나레이션, 배경음악, 화면 효과, 스타일, 내보내기까지 모두 동작합니다. 자동 점검 21개 묶음을 전부 통과했고, 각 단계마다 별도의 검증 과정을 거쳐 발견된 문제를 고쳤습니다. 브라우저를 실제로 띄워 단추를 눌러 보는 점검까지 포함되어 있습니다. 사용설명서는 이 사이트에서 바로 보실 수 있고, 남은 계획은 내 목소리 나레이션입니다. 최신 진행 상황과 검증 근거는 GitHub 저장소의 docs/ROADMAP.md에 적어 두었습니다.

설치 방법

내려받아 실행하면 끝입니다

파이썬이나 FFmpeg를 따로 설치하실 필요가 없습니다. 필요한 것이 모두 설치 파일 안에 들어 있어서, 일반 프로그램처럼 내려받아 실행하시면 됩니다.

설치 파일 내려받기 (Windows · 121MB)

내려받은 파일 실행하기

받은 파일을 더블클릭하면 설치가 시작됩니다. 관리자 권한을 묻지 않으며, 설치가 끝나면 바탕화면에 아이콘이 생깁니다. 그 아이콘을 누르면 브라우저에 작업 화면이 열립니다.

실행할 때 “Windows의 PC 보호”라는 파란 경고창이 뜰 수 있습니다. 개인이 만든 무료 프로그램이라 유료 인증서(연 수십만 원)를 붙이지 않아서 생기는 안내입니다. [추가 정보]를 누른 뒤 [실행]을 누르시면 됩니다. 프로그램 내용은 GitHub에 전부 공개되어 있어 누구나 확인하실 수 있습니다.

소스에서 직접 실행하기 (개발자용)

코드를 직접 보거나 고치고 싶으시다면 이 방법을 쓰실 수 있습니다. 파이썬 3.11 이상과 FFmpeg가 미리 설치되어 있어야 합니다.

winget install Gyan.FFmpeg git clone https://github.com/parkjikoon-hub/moviefit-studio.git

받은 폴더에서 run.bat을 실행하면 필요한 부품과 한글 글꼴을 자동으로 받은 뒤 서버가 켜집니다. 문제가 있을 때는 python tools/check_env.py로 환경을 점검할 수 있습니다.

FAQ

자주 묻는 질문

더 궁금한 점은 GitHub 저장소의 Issues에 남겨 주세요.

정말 무료인가요?
네, 완전히 무료입니다. MIT 라이선스로 공개된 오픈소스이며 유료 기능, 사용 횟수 제한, 결제 유도가 없습니다. 결과물에 워터마크도 찍히지 않고, 만든 자막과 영상은 상업적 용도로도 자유롭게 쓰실 수 있습니다.
인터넷 연결이 필요한가요?
자막 자동 생성은 인터넷 없이 동작합니다. 음성 인식이 컴퓨터 안에서 이루어지기 때문입니다. 다만 처음 설치할 때와, AI 나레이션(TTS)을 만들 때는 인터넷이 필요합니다. 나레이션 음성은 마이크로소프트의 온라인 음성 서비스를 사용하기 때문입니다.
내 영상이 어디로 전송되나요?
영상과 오디오 파일은 어디로도 전송되지 않습니다. 불러온 파일은 컴퓨터 안에서만 처리되고, 결과물도 컴퓨터에 저장됩니다. 단 하나의 예외는 AI 나레이션입니다. 나레이션을 만들 때는 대본 텍스트만 음성 합성 서버로 전송되며, 이 사실은 프로그램 화면에도 안내됩니다. 영상 파일 자체는 이때도 전송되지 않습니다.
맥(Mac)이나 리눅스에서도 되나요?
현재는 윈도우 전용입니다. 윈도우 10과 11에서 동작하도록 만들고 있으며, run.bat과 설치 안내도 윈도우 기준입니다. 맥과 리눅스 지원 계획은 아직 없습니다.
좋은 그래픽카드가 있어야 하나요?
아닙니다. 그래픽카드(GPU)가 없어도 동작합니다. 있으면 자동으로 활용해 더 빨라집니다. CPU만 쓰는 경우 10분짜리 영상의 자막 생성에 몇 분 정도가 걸릴 수 있으며, 진행률이 계속 표시되므로 얼마나 남았는지 확인하실 수 있습니다.
이미 만들어 둔 자막 파일을 불러올 수 있나요?
SRT와 VTT 모두 내보내기·가져오기가 됩니다. 다른 도구와 파일을 자유롭게 주고받는 것이 이 프로젝트의 목표 중 하나입니다.

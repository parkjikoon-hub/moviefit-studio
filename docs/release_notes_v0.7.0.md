**v0.6.0 에서는 나레이션이 만들어지지 않습니다.** 이번 판에서 고쳤으니 v0.6.0 을 쓰고 계시면 새로 설치해 주세요. 타임라인에서 자막과 효과 막대를 끌어서 늘이고 줄이는 일도 훨씬 쉬워졌습니다.

## 고친 것

### 나레이션이 "인터넷 연결을 확인하세요"로 실패하던 문제
v0.6.0 에서 **[음성 만들기]** 를 누르면 인터넷이 멀쩡한데도 이 안내가 뜨고 소리가 하나도 나오지 않습니다. 마이크로소프트가 v0.6.0 에 들어 있는 음성 부품(edge-tts 7.2.8)의 접속을 거절하기 시작했기 때문입니다. 부품을 7.3.1 로 올려 다시 됩니다. 나중에 같은 일이 또 생기면 이제는 인터넷 탓을 하지 않고 "음성 서버가 접속을 거절했습니다. 새 판을 받아 설치해 주세요"라고 알려 줍니다.

### 음성 서버가 잠깐 바쁠 때 나레이션 전체가 멈추던 문제
마이크로소프트 서버가 이따금 "잠시 이용할 수 없음"을 돌려줍니다. 전에는 문장 하나에서 이것을 만나면 나레이션 전체를 포기했습니다. 이제는 잠시 쉬었다가 두 번 더 시도하고, 그래도 안 되면 "음성 서버가 지금 응답하지 않습니다. 몇 분 뒤 다시 눌러 주세요"라고 알려 줍니다.

### 새 판을 설치해도 화면이 예전 그대로이던 문제
브라우저가 작업 화면 파일을 저장해 두고 며칠씩 그대로 썼습니다. 이제는 열 때마다 프로그램에 새 파일이 있는지 확인합니다.

### 창을 닫기 직전에 고친 것이 저장되지 않던 문제
닫기 전 2초 안에 고친 내용이 사라졌습니다. 이제 창을 닫는 순간에도 저장됩니다.

## 달라진 것

### 타임라인에서 끌어서 늘이고 줄이기
막대의 **가운데를 끌면 옮겨지고, 양 끝을 끌면 늘어나거나 줄어듭니다.** 원래 있던 기능인데 잡는 곳이 좁고 안내가 없어서 찾기 어려웠습니다.

- 양 끝 손잡이를 넓혔습니다. 막대에 마우스를 올리면 잡는 곳이 밝아집니다.
- 끄는 동안 막대 위에 `3.20초 → 6.20초 (3.00초)` 처럼 시각이 뜹니다.
- 옆 자막, 재생 위치, 화면 효과 막대의 끝에 가까이 가면 **착 붙고** 노란 세로선이 보입니다. 붙이지 않으려면 `Alt` 를 누른 채 끕니다.
- 자막끼리는 겹치지 않습니다. 옆 자막에 닿으면 거기서 멈춥니다. 화면 효과끼리는 예전처럼 겹쳐도 됩니다.

### 재생 위치 옮기기와 확대
- 타임라인 위쪽 눈금 줄이나 빈 곳을 누르거나 끌면 재생 위치가 그리로 갑니다. 빨간 재생선의 머리를 잡고 끌어도 됩니다.
- `Ctrl` + 마우스 휠로 타임라인을 확대·축소합니다. 마우스가 가리키던 시각은 그 자리에 남습니다. 휠만 굴리면 옆으로 밀립니다.
- 타임라인을 위로 끌어 키우면 막대도 따라 커집니다. 처음 높이도 조금 키웠습니다.

### 되돌리기가 더 많은 것을 되돌립니다
`Ctrl`+`Z` / `Ctrl`+`Y` 가 자막 글자와 모양뿐 아니라 **화면 효과 막대, 화면비, 사진, 대본, 음원을 바꾼 것**까지 되돌립니다. 예전에는 효과 막대를 옮기고 `Ctrl`+`Z` 를 눌러도 효과는 그대로였습니다.

### 안내
처음 열 때 나오는 안내창에 끌기 설명이 들어가 한 번 더 뜹니다. 단축키 표와 사용설명서 5장·9장·17장에도 넣었습니다.

## 알아 둘 것

- **[나레이션 작업]** 에서 자막 막대를 옮겨도 그 문장의 소리는 따라오지 않습니다. 소리의 자리는 **[음성 만들기]** 를 누를 때 정해집니다.
- 영상 자체를 자르는 기능은 없습니다.

## 설치

아래 `MovieFitStudio-Setup.exe` 를 받아 두 번 누르면 끝입니다. 파이썬이나 FFmpeg을 미리 깔 필요가 없습니다. v0.6.0 위에 그대로 설치하면 되고, 만들어 둔 작업은 그대로 남습니다. 설치한 뒤 처음 연 화면에서 막대 끝 손잡이가 넓어지지 않았으면 `F5` 를 한 번 눌러 주세요. 브라우저가 예전 화면을 한 번 더 보여 준 것이고, 그다음부터는 새 화면이 나옵니다.

"Windows에서 PC를 보호했습니다" 창이 뜨면 **[추가 정보] → [실행]** 을 누르세요. 새로 만들어진 프로그램이라 마이크로소프트가 아직 모른다는 뜻이며, 소스는 이 저장소에 전부 공개되어 있습니다.

# PRD — MovieFit Studio (자막·나레이션 스튜디오)

버전 1.0 · 이 문서가 요구사항의 최상위 기준이다.

## 1. 한 줄 정의

일반 영상 파일을 넣으면 **자막을 자동 생성·편집·스타일링·내보내기**하고, 대본을 넣으면 **AI 나레이션과 완벽히 동기화된 자막을 동시에 생성**하는, 무료·로컬 처리·워터마크 없는 Windows용 전용 도구.

## 2. 배경과 목표

사용자는 CapCut을 자막 생성/수정과 나레이션 두 용도로 주로 사용한다. CapCut은 전체 영상편집기라서 이 두 작업에 불필요한 복잡도가 따라오고, 일부 기능은 Pro 결제·클라우드 의존·제한적 자막 편집성 문제가 있다. 목표는 전체 편집기를 복제하는 것이 아니라, **이 두 작업만큼은 CapCut보다 빠르고 정확하고 편하게** 끝내는 도구를 만드는 것이다.

## 3. CapCut 해당 기능 분석

### 3.1 자동 캡션(자막) — CapCut의 흐름

| 단계 | CapCut 동작 | 비고 |
|---|---|---|
| 생성 | 캡션 탭 → 자동 캡션 → 언어 선택 → 클라우드 음성인식 → 타임라인에 캡션 트랙 생성 | 클라우드 업로드 필요, 인식 언어 혼용에 약함 |
| 텍스트 수정 | 캡션 클립 클릭 → 인라인 수정, 또는 일괄 편집 패널에서 목록 수정 | 찾기/바꾸기 없음, 반복 오인식 단어를 하나씩 고쳐야 함 |
| 타이밍 수정 | 타임라인에서 클립 가장자리 드래그 | 미세 조정(±0.1초 단위) 버튼 없음 |
| 분할/병합 | 클립 분할 도구 사용 | 텍스트 기준 분할이 아니라 시간 기준이라 번거로움 |
| 스타일 | 폰트·크기·색·외곽선·그림자·배경·프리셋·애니메이션, "전체 적용" | 강력하나 메뉴 깊이가 깊음 |
| 내보내기 | 영상에 구워서(번인) 내보내기, 데스크톱판은 SRT 내보내기 지원 | SRT **가져오기** 워크플로는 불편 |

### 3.2 나레이션 — CapCut의 흐름

| 기능 | CapCut 동작 | 비고 |
|---|---|---|
| 텍스트 읽어주기(TTS) | 텍스트 클립 선택 → 음성 선택 → 오디오 클립 생성 | 텍스트 수정 시 수동 재생성, 일부 음성 Pro 전용 |
| 녹음 | 마이크 녹음 도구 | 본 프로젝트 범위 외 (P3) |
| 속도/피치 | 오디오 클립 속성에서 조절 | 문장 단위 개별 조절 불가 |
| 자막과의 연동 | 없음 — TTS 오디오와 자막은 별개 트랙, 동기화는 수동 | **가장 큰 불편 지점** |

### 3.3 도출된 핵심 불편 지점 5가지

1. TTS 나레이션과 자막이 따로 놀아 동기화를 손으로 맞춰야 한다.
2. 자막 텍스트를 문서처럼 다룰 수 없다 (찾기/바꾸기·일괄 교정 부재).
3. 반복되는 고유명사 오인식(회사명, 제품명 등)을 매번 다시 고쳐야 한다.
4. 클라우드 처리 의존 — 업로드 대기, 개인정보, 네트워크 필요.
5. 일부 기능·음성의 Pro 과금과 기능 탐색 깊이.

## 4. 차별화 설계 — CapCut을 능가하는 6가지

| # | 차별점 | 설명 |
|---|---|---|
| D1 | **대본 중심 동기화 (킬러 기능)** | 대본 텍스트 → 문장별 TTS 생성 → 각 문장의 실제 오디오 길이로 자막 타이밍을 **자동 계산**. 나레이션과 자막이 태생적으로 완벽 동기화. 문장 하나를 고치면 그 문장의 오디오와 자막만 재생성되고 뒤 타이밍이 자동으로 밀린다. |
| D2 | **문서형 자막 편집기** | 전체 자막을 한 화면 목록으로 보며 인라인 수정, **찾기/바꾸기**, 커서 위치 기준 분할, 인접 세그먼트 병합, ±0.1초 넛지 버튼. |
| D3 | **사용자 사전** | "피엘에스→PLS"처럼 오인식 교정 규칙을 등록하면 음성인식 직후 자동 적용. 프로젝트 간 공유. |
| D4 | **SRT/VTT 자유 입출력** | SRT·VTT 가져오기/내보내기를 1급 기능으로. 다른 도구(YouTube, Premiere)와 자유롭게 오간다. |
| D5 | **로컬 처리·무료·워터마크 없음** | 음성인식은 로컬 Whisper. 영상이 외부로 나가지 않는다. 과금·워터마크 없음. |
| D6 | **평평한 UI** | 자막·나레이션에 필요한 것만 한 화면에. 메뉴 깊이 최대 2단계. |

## 5. 핵심 사용자 시나리오

### 시나리오 A — 영상에서 자막 만들기
1. 영상 파일(mp4 등)을 드래그해서 가져온다.
2. [자막 자동 생성] 클릭 → 언어와 모델 크기 선택 → 진행률 표시 → 자막 목록 생성.
3. 사용자 사전이 자동 적용된 목록에서 오타를 인라인 수정하고, 필요하면 찾기/바꾸기로 일괄 교정.
4. 플레이어에서 자막이 실시간 오버레이로 보이며, 세그먼트를 클릭하면 그 시점으로 이동.
5. 스타일 프리셋을 고르고(또는 세부 조정), [내보내기]에서 SRT 또는 자막이 구워진 영상(mp4)을 선택.

### 시나리오 B — 대본으로 나레이션+자막 만들기
1. [대본 모드]에 대본을 붙여넣는다 (또는 시나리오 A의 자막을 대본으로 전환).
2. 음성(한국어 남/녀 등)과 속도를 고르고 [미리듣기]로 확인.
3. [나레이션 생성] → 문장별 오디오 생성 + 문장 간 간격 설정 → 자막 타이밍 자동 산출.
4. 특정 문장만 텍스트·속도를 고쳐 [이 문장만 재생성] → 이후 타이밍 자동 재계산.
5. [내보내기]: ① 나레이션 오디오(mp3/wav)+SRT ② 기존 영상에 나레이션 입히고(원본 소리 볼륨 조절/덕킹) 자막 번인한 mp4.

## 6. 기능 요구사항

우선순위: **P1 = MVP 필수**, P2 = 정식판, P3 = 이후.

### 프로젝트/파일
- F-01 (P1) 영상 파일 가져오기: mp4, mov, mkv, webm / 오디오 mp3, wav, m4a
- F-02 (P1) 프로젝트 자동 저장(JSON) 및 다시 열기 — 프로그램을 껐다 켜도 작업이 유지된다
- F-03 (P1) SRT 내보내기 / F-04 (P2) SRT·VTT 가져오기, VTT 내보내기

### 자막 생성 (STT)
- F-10 (P1) 로컬 Whisper 기반 자동 자막: 언어(한/영/자동), 모델 크기(small/medium) 선택, 진행률 표시
- F-11 (P1) 세그먼트 자동 분할: 문장 부호와 최대 글자수(기본 한 줄 20자, 2줄) 기준
- F-12 (P2) 사용자 사전 자동 교정 (D3)
- F-13 (P3) 단어 단위 타임스탬프 기반 세그먼트 재분할

### 자막 편집
- F-20 (P1) 세그먼트 목록: 시간·텍스트 표시, 인라인 텍스트 수정, 클릭 시 해당 시점으로 플레이어 이동
- F-21 (P1) 세그먼트 추가/삭제/병합/분할, 시작·끝 시간 ±0.1초 넛지 버튼과 직접 입력
- F-22 (P2) 찾기/바꾸기 (전체/선택 범위)
- F-23 (P2) 실행 취소/다시 실행 (Ctrl+Z/Y)
- F-24 (P1) 플레이어 실시간 자막 오버레이 (스타일 반영)
- F-25 (P1) 자막 타임라인 띠: 자막을 막대로 보여 주고 끌어서 이동·길이 조절, 재생 위치 표시, 확대/축소
- F-26 (P1) 읽기 속도 검사: 초당 글자수가 높은 자막을 색으로 경고하고, [자막 검사]로 겹침·빈 자막·너무 짧음을 한 번에 점검
- F-27 (P2) 전체 시간 밀기: 자막 전체를 ±n초 이동 (인트로를 나중에 붙였을 때 필요)

### 자막 스타일
- F-30 (P2) 폰트(번들 한글 폰트 포함)·크기·색·외곽선·그림자·배경(반투명 박스)·위치(상/중/하)·정렬
- F-31 (P2) 프리셋 5종 (기본 흰색+검은 외곽선 / 유튜브 예능형 / 뉴스 하단바 / 미니멀 / 강조 노랑) + 사용자 프리셋 저장
- F-32 (P2) 전체 적용이 기본, 세그먼트별 개별 스타일은 P3
- F-33 (P2) **자막 자유 위치 배치**: 플레이어의 자막을 마우스로 끌어 원하는 자리에 놓는다. 좌표 직접 입력과 [기본 위치로 되돌리기]도 제공. 번인 시 ASS `\pos` 태그로 같은 자리에 새겨진다
- F-34 (P3) 안전 영역 표시: 쇼츠·릴스에서 앱 UI에 가려지는 영역을 화면에 안내선으로 표시

### 나레이션 (TTS)
- F-40 (P1) 대본 입력 → 문장 분할 → 문장별 TTS 생성 → 이어붙인 나레이션 오디오 생성
- F-41 (P1) 한국어/영어 음성 선택 + 3초 미리듣기, 전체 속도 조절
- F-42 (P1) **자막 타이밍 자동 산출**: 각 문장 오디오의 실제 길이 + 문장 간 간격(기본 0.3초, 조절 가능) (D1)
- F-43 (P2) 문장 단위 재생성(텍스트/속도 수정 후 해당 문장만) + 이후 타이밍 자동 재계산
- F-44 (P2) 자막→대본 전환 (시나리오 A 결과를 나레이션 재녹음용 대본으로)
- F-45 (P2) **마이크 녹음**: 브라우저에서 직접 녹음해 프로젝트에 저장. 목소리 등록(F-46)의 전제이며, AI 목소리 대신 직접 녹음하려는 사용자를 위한 기능
- F-46 (P2) **내 목소리 나레이션**: 본인 목소리를 짧게 등록해 두면 그 목소리로 나레이션을 만든다. 엔진은 `TTSEngine` 어댑터 뒤에 선택 설치로 붙인다. UI에 "본인 목소리만 등록" 안내를 명시한다
- F-47 (P2) 목소리 선택 확대: edge-tts 322개 음성을 언어·성별로 검색·필터하고 미리듣기. 한국어 전용 3개 + 한국어를 읽을 수 있는 다국어 음성 11개를 우선 노출
- F-48 (P3) 나레이션 읽기 사전: 숫자·영어 약어를 어떻게 읽을지 등록 (예: 3D → 쓰리디)

### 내보내기 (렌더링)
- F-50 (P1) 자막 번인 mp4 (FFmpeg + ASS 스타일)
- F-51 (P1) 나레이션 합성 mp4: 원본 오디오 볼륨 0~100% 조절, (P2) 나레이션 구간 자동 덕킹
- F-52 (P1) 나레이션 오디오 단독 내보내기 (mp3/wav)
- F-53 (P2) 내보내기 진행률 표시와 완료 후 폴더 열기 버튼

## 7. 비기능 요구사항

- N-01 대상 환경: Windows 10/11, 크롬 계열 브라우저. GPU 없어도 동작(있으면 자동 활용).
- N-02 처리 시간 안내: CPU 기준 10분 영상 자막 생성 수 분 수준을 목표로 하되, 항상 진행률을 표시해 체감 대기를 줄인다.
- N-03 개인정보: 영상·오디오는 외부 전송 금지 (TTS 텍스트 전송은 예외, UI에 고지).
- N-04 언어: UI 전체 한국어.
- N-05 안정성: 렌더링 중 실패 시 원본 파일은 절대 손상되지 않는다 (출력은 항상 새 파일).

## 8. 명시적 비목표 (Non-Goals)

- 멀티트랙 영상 편집, 컷 편집, 전환/필터/스티커/이펙트 — 만들지 않는다.
- CapCut 프로젝트 파일(.draft) 호환 — 비공개 형식이므로 지원하지 않는다.
- 모바일 앱, 클라우드 협업, 계정 시스템 — 만들지 않는다.
- CapCut UI 자산(아이콘·로고·그래픽) 복제 — 금지.

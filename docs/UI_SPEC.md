# UI SPEC — MovieFit Studio 화면 설계

버전 1.0 · CapCut의 익숙한 배치(좌: 소스, 중: 플레이어, 우: 속성, 하: 타임라인)를 참고하되, 자막·나레이션에 불필요한 요소를 전부 제거한 "평평한" 구성. CapCut의 아이콘·그래픽 자산은 사용하지 않는다.

## 1. 전체 레이아웃 (단일 페이지)

```
┌────────────────────────────────────────────────────────────────┐
│ 상단바: 프로젝트명 | [영상 모드 | 대본 모드] 전환 | 저장상태 | [내보내기] │
├───────────────┬──────────────────────────────┬─────────────────┤
│ 좌 패널        │  중앙: 플레이어               │ 우 패널          │
│ (모드별 전환)   │  - <video> + 자막 오버레이     │ [스타일] 탭      │
│ 영상 모드:     │  - 재생/일시정지, 시간표시      │  프리셋 5종 카드  │
│  파일 정보     │  - 자막 클릭 시 해당 세그먼트   │  폰트/크기/색     │
│  [자막 자동    │    편집으로 포커스 이동         │  외곽선/그림자/배경│
│   생성] 버튼   │                              │  위치/정렬       │
│  언어·모델 선택│                              │ [나레이션] 탭    │
│ 대본 모드:     │                              │  음성 선택+미리듣기│
│  대본 입력창   │                              │  속도, 문장 간격  │
│  [나레이션     │                              │  원본 소리 볼륨   │
│   생성] 버튼   │                              │ [사전] 탭        │
├───────────────┴──────────────────────────────┴─────────────────┤
│ 하단: 자막 세그먼트 편집기 (목록형, 스크롤)                          │
│  검색/찾기·바꾸기 바 | [＋추가]                                    │
│  ┌ #  시작→끝  [◀0.1][0.1▶]  텍스트(인라인 편집)  [분할][병합][삭제][🔊]│
│  현재 재생 중인 세그먼트는 하이라이트 + 자동 스크롤                    │
└────────────────────────────────────────────────────────────────┘
```

핵심 사상: **타임라인 드래그 대신 목록 편집.** 자막 작업의 90%는 텍스트 교정이므로, 문서 편집기처럼 다루게 한다 (차별점 D2). 시간 조정은 넛지 버튼(±0.1초)과 직접 입력으로 해결 — CapCut의 클립 가장자리 드래그보다 정밀하고 실수도 적다.

## 2. 화면별 상세

### 2.1 시작 화면
- 큰 드롭 영역: "영상을 끌어다 놓거나 클릭해서 선택" + [대본으로 시작하기] 버튼.
- 최근 프로젝트 목록 (이름, 날짜, 이어서 열기).

### 2.2 자막 자동 생성 (영상 모드)
- 좌 패널에서 언어(한국어/영어/자동 감지)와 정확도(빠름=small / 정확=medium, 각각 예상 시간 안내) 선택 → [자막 자동 생성].
- 진행률 바 + "음성을 인식하고 있습니다 (2/10분)" 식의 진행 문구. 완료 시 하단 편집기에 목록 채워짐.
- 이미 자막이 있으면 "기존 자막을 덮어씁니다" 확인 대화상자 (파괴적 작업).

### 2.3 세그먼트 편집기 (하단, 공통)
- 인라인 편집: 텍스트 클릭 → 즉시 수정, Enter로 확정, Esc 취소.
- 분할: 텍스트 편집 중 커서 위치에서 Ctrl+Enter → 그 지점 기준 두 세그먼트로 분할(시간은 글자수 비례 배분).
- 병합: 세그먼트의 [병합] 버튼 → 다음 세그먼트와 합침.
- 넛지: 시작/끝 각각 ±0.1초 버튼, 시간 클릭 시 직접 입력(mm:ss.d).
- 찾기/바꾸기: 상단 바에서 검색어 입력 → 일치 세그먼트만 필터 표시, [모두 바꾸기].
- 🔊 버튼(대본 모드): 해당 문장 나레이션만 재생. 텍스트 수정 후엔 [이 문장 재생성] 버튼이 나타난다.

### 2.4 나레이션 (대본 모드)
- 좌 패널 대본 입력창에 붙여넣기 → [문장 나누기] 미리보기 → [나레이션 생성].
- 우 패널 [나레이션] 탭: 음성 카드(이름·성별·언어, ▶미리듣기 3초), 전체 속도 슬라이더, 문장 간 간격(초), 원본 소리 볼륨(영상이 있을 때만).
- 영상 모드에서 [자막을 대본으로] 버튼 → 대본 모드로 전환하며 자막 텍스트를 대본으로 가져옴 (F-44).

### 2.5 스타일 (우 패널)
- 프리셋 카드 5종: 기본(흰+검은 외곽선) / 예능(굵은 노랑+두꺼운 외곽선) / 뉴스(하단 반투명 바) / 미니멀(얇은 흰색) / 강조(흰+노랑 키워드용).
- 세부: 폰트(번들 폰트 목록), 크기 슬라이더, 색, 외곽선 색/두께, 그림자 on/off, 배경 박스 on/off+투명도, 위치(상/중/하), 정렬.
- 변경 즉시 플레이어 오버레이에 반영 (style_map 기준).
- [내 프리셋으로 저장].

### 2.6 내보내기 대화상자
- 선택지: ① SRT 파일 ② VTT 파일 ③ 자막 입힌 영상(mp4) ④ 나레이션 오디오(mp3/wav) ⑤ 나레이션+자막 영상(mp4).
- 각 항목에 한 줄 설명. 진행률 표시, 완료 시 [폴더 열기].

## 3. 키보드 단축키

| 키 | 동작 |
|---|---|
| Space | 재생/일시정지 (텍스트 편집 중 아닐 때) |
| ←/→ | 1초 이동, Shift+←/→ 0.1초 |
| ↑/↓ | 이전/다음 세그먼트 선택 |
| Enter | 선택 세그먼트 텍스트 편집 시작 |
| Ctrl+Enter | (편집 중) 커서 위치에서 분할 |
| Ctrl+Z / Ctrl+Y | 실행 취소 / 다시 실행 |
| Ctrl+F | 찾기/바꾸기 |

## 4. 디자인 톤

- 다크 테마 기본 (영상 작업 표준), 배경 #17181C 계열, 포인트 색 1가지(청록 계열), 한글 UI 폰트는 시스템 기본 또는 번들 폰트.
- 아이콘은 오픈소스 세트(예: lucide) 사용. CapCut 자산 복제 금지.
- 모든 버튼·라벨은 한국어, 위험 동작(덮어쓰기/삭제)은 확인 대화상자.

## 5. CapCut 대비 사용성 개선 요약 (검수용)

1. 자막 교정: 클립 클릭 반복 → **문서형 목록 + 찾기/바꾸기 + 사전**
2. TTS-자막 동기화: 수동 → **자동 (문장 오디오 실측 길이 기반)**
3. 시간 미세조정: 드래그 → **±0.1초 넛지 + 직접 입력**
4. 내보내기: 번인 중심 → **SRT/VTT/오디오/영상 자유 선택**
5. 기능 탐색: 깊은 메뉴 → **한 화면, 탭 2단계 이내**

# ROADMAP — 개발 단계와 수용 기준

각 Phase는 **앞 Phase의 수용 기준이 전부 통과된 뒤에만** 시작한다. 수용 기준 검증은 검증 서브에이전트가 직접 실행해서 확인한다 (CLAUDE.md의 자체 검증 규칙).

---

## Phase 0 — 환경 준비와 뼈대 (반나절)

**목표**: 사용자 PC에서 "run.bat 더블클릭 → 브라우저에 빈 화면"까지.

작업:
- `tools/check_env.py`: Python 버전, FFmpeg 존재, 필수 패키지를 점검하고, 없으면 **비개발자가 따라할 수 있는 설치 안내를 한국어로 출력**
- FFmpeg 미설치 시 설치 안내 (winget 또는 다운로드+압축해제+경로 안내 중 쉬운 쪽 추천)
- FastAPI 서버 뼈대 + static 서빙 + `run.bat`(서버 기동 후 브라우저 자동 열기)
- `tests/sample/` 생성: FFmpeg로 10초 테스트 영상(색 바 + 톤) 생성, 짧은 한국어 대본 텍스트 파일
- 번들 한글 폰트 다운로드(`assets/fonts/`, OFL 라이선스 명시)
- 프로젝트 생성/저장/열기 API + JSON 저장 구조 (TECH_SPEC 5절)

수용 기준:
- [ ] `python tools/check_env.py` 실행 시 전 항목 OK 또는 명확한 한국어 설치 안내가 출력된다
- [ ] `run.bat` 더블클릭으로 브라우저가 열리고 시작 화면 뼈대가 보인다
- [ ] 프로젝트를 만들고 서버를 껐다 켜도 최근 프로젝트 목록에 남아 있다
- [ ] `tests/sample/`에 재생 가능한 샘플 영상이 존재한다

## Phase 1 — 영상→자막 MVP (시나리오 A 최소 동작)

**목표**: 영상을 넣고 자막을 자동 생성해 목록에서 고친 뒤 SRT로 내보낸다.

작업: F-01, F-02, F-03, F-10, F-11, F-20, F-21, F-24, F-50, 진행률(jobs)

수용 기준:
- [ ] 샘플 영상(사람 음성 포함 파일 — 사용자에게 실제 영상 1개 요청)을 가져와 자막이 자동 생성된다. 생성 중 진행률이 표시된다
- [ ] 세그먼트 텍스트를 인라인 수정하면 2초 내 자동 저장되고, 새로고침해도 유지된다
- [ ] 세그먼트 병합/분할/삭제/±0.1초 넛지가 동작하고 플레이어 오버레이에 즉시 반영된다
- [ ] 세그먼트 클릭 시 플레이어가 해당 시점으로 이동한다
- [ ] SRT 내보내기 파일이 메모장에서 올바른 형식으로 열리고, 유튜브 업로드 형식과 호환된다
- [ ] 자막 번인 mp4가 생성되고 한글이 깨지지 않는다 (번들 폰트 확인)
- [ ] 서버 콘솔에 처리되지 않은 예외가 없다

## Phase 2 — 나레이션과 대본 모드 (시나리오 B, 킬러 기능 D1)

**목표**: 대본 → 나레이션 오디오 + 완벽 동기화 자막.

작업: F-40, F-41, F-42, F-51, F-52, 모드 전환 UI

수용 기준:
- [ ] 대본을 붙여넣고 나레이션을 생성하면 문장별 mp3와 이어붙인 전체 오디오가 생성된다
- [ ] 자막 타이밍이 각 문장 오디오의 **ffprobe 실측 길이**로 산출되어, 재생 시 소리와 자막이 어긋나지 않는다 (검증자가 직접 듣고/파형으로 확인)
- [ ] 음성 미리듣기가 3초 내 재생된다
- [ ] 영상에 나레이션을 입힐 때 원본 소리 볼륨 조절이 반영된다
- [ ] 나레이션 오디오 단독(mp3) + SRT 동시 내보내기가 된다
- [ ] edge-tts 호출 실패 시 프로그램이 죽지 않고 한국어 안내 메시지가 뜬다

## Phase 3 — 편집 완성도 (CapCut 추월 지점)

**목표**: 스타일, 찾기/바꾸기, 사전, 문장 재생성.

작업: F-12, F-22, F-23, F-30, F-31, F-43, F-44, F-04, F-53

수용 기준:
- [ ] 프리셋 5종이 오버레이와 번인 결과 양쪽에 일관되게 적용된다 (style_map 단일 출처 확인)
- [ ] 찾기/바꾸기로 특정 단어를 전체 교체할 수 있다
- [ ] 사용자 사전에 규칙을 넣고 STT를 다시 돌리면 자동 교정이 적용된다
- [ ] 대본 모드에서 한 문장만 수정 후 재생성하면 그 문장 오디오만 다시 만들어지고 이후 타이밍이 자동 재계산된다
- [ ] Ctrl+Z로 직전 편집이 되돌려진다
- [ ] SRT/VTT 가져오기가 동작한다

## Phase 4 — 마감 품질

**목표**: 매일 쓰는 도구 수준의 안정성.

작업: 단축키 전체(UI_SPEC 3절), 덕킹(F-51 P2), 내보내기 폴더 열기, 오류 메시지 전수 한국어화, 긴 영상(30분+) 성능 점검, 사용자 매뉴얼(USER_GUIDE.md) 작성

수용 기준:
- [ ] UI_SPEC 3절의 단축키가 모두 동작한다
- [ ] 30분 영상에서 STT·렌더링이 완료되고 진행률이 정확하다
- [ ] 의도적으로 잘못된 입력(없는 파일, 빈 대본, 지원 안 되는 형식)을 넣어도 죽지 않고 한국어 안내가 뜬다
- [ ] USER_GUIDE.md만 보고 처음 쓰는 사람이 시나리오 A·B를 완료할 수 있다

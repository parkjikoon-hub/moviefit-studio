## Phase 1 — 영상→자막 MVP (시나리오 A)

**목표**: 영상을 넣고 자막을 자동 생성해 목록에서 고친 뒤 SRT로 내보낸다.

작업: F-01, F-02, F-03, F-10, F-11, F-20, F-21, F-24, F-25, F-26, F-50, 진행률(jobs)

수용 기준:
- [ ] 사람 음성이 든 실제 영상에서 자막이 자동 생성되고, 생성 중 진행률이 표시된다
- [ ] 세그먼트 텍스트를 고치면 2초 내 자동 저장되고 새로고침해도 유지된다
- [ ] 병합/분할/삭제/±0.1초 넛지가 동작하고 플레이어 오버레이에 즉시 반영된다
- [ ] 타임라인 막대를 끌어 시간을 조절하면 목록과 오버레이가 함께 갱신된다 (F-25)
- [ ] 읽기 속도가 빠른 자막이 노란색/빨간색으로 표시된다 (F-26)
- [ ] SRT 파일이 메모장에서 올바른 형식으로 열리고 유튜브와 호환된다
- [ ] 자막 번인 mp4에서 한글이 깨지지 않는다 (번들 폰트 확인)
- [ ] 서버 콘솔에 처리되지 않은 예외가 없다

## Phase 2 — 나레이션과 대본 모드 (시나리오 B, 킬러 기능 D1)

**목표**: 대본 → 나레이션 오디오 + 완벽 동기화 자막.

작업: F-40, F-41, F-42, F-43, F-44, F-51, F-52

수용 기준:
- [ ] 대본을 붙여넣고 나레이션을 생성하면 문장별 mp3와 이어붙인 전체 오디오가 생성된다
- [ ] 자막 타이밍이 각 문장 오디오의 **ffprobe 실측 길이**로 산출되어 소리와 어긋나지 않는다
- [ ] 음성 미리듣기가 3초 내 재생된다 *(Phase 0에서 선행 구현 — 실제 동작 확인됨)*
- [ ] 한 문장만 고쳐 재생성하면 그 문장 오디오만 다시 만들어지고 이후 타이밍이 자동 재계산된다 (F-43)
- [ ] 자막을 대본으로 옮기는 버튼이 동작한다 (F-44)
- [ ] 영상에 나레이션을 입힐 때 원본 소리 볼륨 조절이 반영된다
- [ ] 나레이션 오디오 단독(mp3) + SRT 동시 내보내기가 된다
- [ ] edge-tts 호출 실패 시 프로그램이 죽지 않고 한국어 안내가 뜬다

## Phase 3 — 편집 완성도

**목표**: 사전, 찾기/바꾸기, 실행 취소, 스타일 번인 일치.

작업: F-12, F-22, F-23, F-30, F-31, F-32, F-33, F-04, F-53

수용 기준:
- [ ] 프리셋 5종이 오버레이와 번인 결과 양쪽에 **일관되게** 적용된다 (style_map 단일 출처 확인)
- [ ] 마우스로 끌어 놓은 자막 위치가 번인 결과에서도 같은 자리에 나온다 (F-33, ASS `\pos` 검증)
- [ ] 찾기/바꾸기로 특정 단어를 전체 교체할 수 있다
- [ ] 사용자 사전에 규칙을 넣고 STT를 다시 돌리면 자동 교정이 적용된다
- [ ] Ctrl+Z로 직전 편집이 되돌려진다
- [ ] SRT/VTT 가져오기가 동작한다
- [ ] 내보내기 진행률이 표시되고 완료 후 [폴더 열기]가 동작한다

## Phase 4 — 내 목소리와 고급 기능

**목표**: 사용자 본인 목소리로 나레이션, 마이크 녹음, 자동 덕킹.

작업: F-13, F-45, F-46, 자동 덕킹(F-51 P2)

- **F-45 마이크 녹음** — 브라우저 MediaRecorder로 녹음해 프로젝트에 저장. 목소리 등록의 전제이자, 직접 나레이션을 녹음하려는 사용자를 위한 기능.
- **F-46 내 목소리 나레이션** — 등록한 목소리 샘플로 나레이션 생성. 엔진 선정은 `docs/RESEARCH_voice_cloning.md`의 결론을 따른다. `TTSEngine` 어댑터 뒤에 붙이며, 용량이 크므로 **선택 설치**로 분리한다.
- **F-13 단어 단위 타임스탬프 재분할** — Whisper의 단어별 시각을 이용해 자막을 더 자연스러운 지점에서 끊는다.
- **자동 덕킹** — 나레이션이 나오는 구간에서만 원본 소리를 자동으로 줄인다 (`sidechaincompress`).

수용 기준:
- [ ] 마이크로 10초 녹음 → 저장 → 재생이 된다
- [ ] 등록한 목소리로 만든 나레이션이 원래 목소리와 알아들을 수 있게 닮았다 (사용자 청취 확인)
- [ ] 목소리 등록 화면에 "본인 목소리만 등록" 안내가 명시되어 있다
- [ ] 선택 설치가 실패해도 기본 나레이션(edge-tts)은 정상 동작한다
- [ ] 덕킹을 켜면 나레이션 구간의 원본 소리가 실제로 줄어든다 (파형 확인)

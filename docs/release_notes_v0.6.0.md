영상의 **원하는 구간에만** 비·눈·흑백 같은 **화면 효과 16가지**를 걸 수 있습니다. 사용설명서에도 새 장이 생겼습니다.

## 새로 생긴 것

### 화면 효과 16가지
**[자막 작업]** 화면 오른쪽에 **화면 효과** 묶음이 생겼습니다. 효과 이름을 누르면 지금 재생 위치에 **3초짜리 막대**가 하나 생기고, 타임라인에서 **끌어서 옮기고 양 끝을 잡아 길이를 바꿉니다.** 여러 개를 놓아도 되고 겹쳐도 됩니다.

| 갈래 | 효과 |
|---|---|
| 움직임 | 줌 강조 |
| 날씨 | 비 · 눈 · 물방울 맺힘 |
| 꾸밈 | 비눗방울 · 작은 폭죽 |
| 시선 모으기 | 부분 흐림 · 주변 어둡게 · 가장자리 어둡게 · 네모 테두리 |
| 색감 | 밝기·대비·채도 · 따뜻하게 · 차갑게 · 선명하게 · 빈티지 · 흑백 |

- **세기 3단계** — [약하게] [보통] [많이]. 세 단계가 눈에 띄게 다르도록 값을 맞췄고, 가장 센 [많이]조차 **화면을 가리지 않는 선**을 넘지 않게 상한을 두었습니다.
- **진하기(투명 정도) 슬라이더** — 화면 전체를 덮는 효과 9가지(비·눈·주변 어둡게·가장자리 어둡게·따뜻하게·차갑게·선명하게·빈티지·흑백)에 붙었습니다. 20~200%이고 기본 100%가 그대로 쓰기 좋은 값입니다.
- **효과마다 다른 값** — 자리(가로·세로), 크기, 너비·높이, 떨어지는 속도, 밝기·대비·채도를 슬라이더로 조절합니다.
- **10초 미리보기에도 그대로 나옵니다.** 전체를 다 만들기 전에 확인할 수 있습니다.
- **자막은 효과 위에 그려집니다.** 흑백 효과를 걸어도 자막 색은 그대로입니다.

> 얼굴이나 개인정보를 가려야 하면 **부분 흐림**을 쓰세요. 네모의 자리와 크기를 슬라이더로 맞춥니다.

### 사용설명서에 9장이 생겼습니다
**9장 화면 효과 넣기** — 16가지 표, 세기, 값 슬라이더, 걸리는 시간까지 담았습니다. 옛 9~19장은 10~20장으로 밀렸습니다. 프로그램 안 **[사용설명서]** 와 소개 사이트 양쪽에 반영되어 있습니다.

## 고친 것

- **주변 어둡게가 화면을 보라색으로 물들이던 문제.** 밝기만 줄이고 색은 그대로 두어, 어두워질수록 색이 진해지고 있었습니다(밝기에 견준 색 150% → 101%). 검은 그림을 **투명도로 얹는** 방식으로 바꿔 고쳤습니다.
- **비·눈이 배경색을 머금던 문제.** 밝기만 올리는 방식이라 풀밭 위의 빗줄기가 초록빛이었습니다. 이제 흰 빗줄기·눈송이가 제 색으로 나옵니다(색의 진하기 비 20.9% → 15.4%, 눈 18.6% → 13.3%).
- 물방울·비눗방울·폭죽이 화면에 견줘 너무 컸던 것을 줄였습니다. 작아진 만큼 개수와 굵기를 함께 올려 세기 3단계의 차이는 그대로 둡니다.
